# LUT POS - Sistema de Ponto de Venda

Sistema de Ponto de Venda para pequenos negocios.

## Funcionalidades

- Vendas com calculo de IVA
- Controlo de stock
- Multiplos metodos de pagamento (Dinheiro, M-Pesa, e-Mola, mKesh)
- Gestao de produtos
- Utilizadores com perfis (Admin e Caixa)
- Relatorios em PDF
- Backup e restauro
- Funciona offline
- Instalavel como app (PWA)

## Como instalar

1. Abra o link no Chrome
2. Clique nos 3 pontos
3. Instalar aplicativo ou Adicionar a tela inicial

## Tecnologias

- HTML5, CSS3 (TailwindCSS)
- JavaScript
- SQLite (sql.js)
- PWA (Progressive Web App)
